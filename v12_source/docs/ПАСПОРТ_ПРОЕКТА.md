# NEXUS LAB V12 - паспорт технической сборки

## Цель
Отобрать учебные точки, дающие лучшую способность нейросети узнавать ранее не виденные движения цены. Результаты LONG и SHORT всегда раздельны. Денежный результат не входит в оценку генетического поиска.

## Что работает
- 5 размеров свечей SBRF: 1,5,10,15,30 минут. Файлы заранее подготовлены из выгрузки Финама. Время исходного файла сохранено; часовой пояс не заявлен.
- 50 поколений x 36 особей по умолчанию на каждый из 10 опытов = 18 000 плановых оценок (с повторами). Предел множества сочетаний при этом не достигается; фактическое число разных особей хранится отдельно.
- Каждая особь содержит ПОЛНЫЙ состав учебных положительных примеров, отдельно исходные, более ранние и новые предложенные. Состав закодирован в base64(zlib(uint32[])); decode_ids в research/evolve_datasets.py.
- При мутации часть точек сохраняется от родителей. Доступны увеличение, сокращение, замена, смешивание, новое случайное исследование, добавление ранних и ранее неотмеченных точек.
- Подбор нейросети с нуля для каждого действительно нового варианта: PyTorch AdamW, веса .003, мини-пакеты 384, 24 прохода по умолчанию, новая и та же сеть для честного сравнения обучающих групп.
- На проходах 1,2,4,8,12,16,24 (если доступны) записаны ошибки на знакомых и более поздних данных, качество распознавания и длительность. Это помогает увидеть момент перехода от обучения к запоминанию.
- Для победителя: проверка на сентябрьских днях, сравнение с полной исходной базой, 3 случайными группами, перемешанной разметкой и 2 повторными стартами.
- Полная запись каждого варианта в CANDIDATES.jsonl. GENERATIONS.json - сводная динамика по поколениям. RESULT.json - финал.
- Короткий восстановительный запуск: START.py --smoke. Рабочий запуск: START.py.
- Все записи находятся в results/SMOKE или results/FULL. Перезапуск сохраняет прогресс.

## Откуда берутся метки
В исходном примере рост = цена через ровно 60 минут больше текущей минимум на 0.25%, падение = меньше на 0.25%. Используются только внутридневные сравнения без переноса через ночной разрыв. Это только рабочее правило для опыта.

## Как оценивается вариант
Нейросеть не обучается на днях SELECT (17-28 августа 2026), только прогнозирует их. Из двух временных частей SELECT берётся 70% худшей относительной оценки и 30% среднего, небольшой штраф за отличие между половинами и очень малое число разных дней. Относительная оценка = точность ранжирования входов (average precision) / доля положительных меток. Чем выше, тем лучше. CHECK (сентябрь) не участвует в выборе.

## Размеры и ограничения
- Архив кода не содержит рыночные файлы. При первом запуске нужны обе части NEXUS_FINAM_PREPARED_A/B.zip.
- 18 000 кандидатов могут исполняться много часов; скорость зависит от модели, CPU/GPU и количества строк. Не обещаем фиксированную длительность.
- В V12 поиск примеров пока идёт на одной фиксированной нейросети. Старый многомодельный V10/V11 сохранён в legacy/V10_V11_ORIGINAL_CODE.zip. Дальнейшее разветвление архитектур проводится отдельным экспериментом, иначе сложно понять пользу именно отбора примеров.
- Исследование не подключается к бирже и не ставит ордера.
- Для ускорения fit_predict использует CUDA, если она доступна; эта сборка проверена на местном CPU, GTX 1070 пользователя в новой версии ещё не испытана.
- У записей исходных данных уже есть будущие значения для разметки, но их нет среди признаков нейросети. Исходный отбор новых точек анализирует будущее в рамках учебной части истории; для живого сигнала оно недоступно. Нельзя использовать результат CHECK при поиске.
- На данном этапе не реализованы многодневная перебалансировка по рынкам и автоматический перебор архитектур внутри GA; отдельная задача.

## Что возвращает отчёт
NEXUS_V12_REPORT.zip содержит результаты, поэтапные оценки обучения, сводные журналы и конституцию. Полные закодированные хромосомы остаются в results/.../CANDIDATES.jsonl на компьютере пользователя и не дублируются в компактном отправляемом архиве. Если понадобится отдельный полный разбор, можно архивировать нужную папку результатов.

## Как проверить корректность
`python START.py --smoke --cpu`
`python -m pytest -q tests/test_v12.py`

Старый V10/V11 код вынесен из корня не потому, что его функции бесполезны, а чтобы он не мешал запуску. Он сохранён целиком в архиве `legacy`.
