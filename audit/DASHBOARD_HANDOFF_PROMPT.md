# Передача дашборда другому ИИ-чату

Продолжи разработку лаборатории просмотра разметки и тестов на истории. Говори по-русски короткими простыми предложениями. Не отправляй реальные заявки и не подключай торговые ключи.

Получение без авторизации:

```sh
git clone https://github.com/mavar/nexus-lab-v12-audit-public.git
cd nexus-lab-v12-audit-public
```

Это отдельный публичный снимок, а не смена видимости исходного закрытого репозитория. Код дашборда лежит в dashboard_source/, скопирован из проверенной версии 9515e54aff9fadf80a1c8f752ac1720aecf16086 без Git-истории, секретов, local-config и установленных зависимостей. Производственный исходник владельца остаётся закрытым. Не меняй его настройки доступа.

Прочитай dashboard_source/AGENTS.md, DASHBOARD_GUIDE.md, TEST_LAB_SETUP.md и проектный паспорт. Общие правила этого публичного комплекта находятся в корневом AGENTS.md; ссылки на рабочие диски владельца в старых документах не означают доступ к ним в твоей среде.

Стек: Next.js+TypeScript+Tailwind+Recharts, локальный FastAPI. Нужны Python 3.12, Node.js 24+, npm, Git. Официальные инструменты: https://www.python.org/downloads/ , https://nodejs.org/ , https://git-scm.com/downloads . Python/Node зависимости и lock-файлы лежат в dashboard_source. Ничего платного не покупать.

## Быстрая проверка интерфейса без рынка

На Windows:

```powershell
Set-Location dashboard_source
.\SETUP_LAB.bat -Demo
.\START_LAB.bat
```

Ожидание первой установки: 5–20 минут, зависит от сети; повторный старт обычносекунды. Открывается http://127.0.0.1:8767/ . Демо явно помечено искусственными ценами; по нему нельзя доказывать торговый результат. Сеть нужна для зависимостей, но не для отправки торговых заявок — её нет.

## Восстановление на настоящих данных

ОткрытыйZIP:
https://github.com/mavar/nexus-lab-v12-audit-public/releases/download/review-2026-11-19-v2/SOLUSDT_two_weeks_ticks_20260614_27.zip

Скачай его в корень клона. Из корня запусти:

```powershell
python tools/configure_dashboard_data.py --archive SOLUSDT_two_weeks_ticks_20260614_27.zip
Set-Location dashboard_source
.\SETUP_LAB.bat
.\START_LAB.bat
```

Скрипт проверяет безопасные пути иSHA256, распаковывает 28 реальныхParquet в market_ticks/, создаёт только локальный исключённый из Git конфигquoteRoot/tradeRoot. Предыдущий локальный конфиг сохраняется резервной копией. API читает 14–20 июня;21–27 июня — более поздняя история для проверки. Исходные данные содержат разрывы; не дорисовывать их. Для автономной страницы разметки отдельно выполнить:

```powershell
.venv\Scripts\python.exe build.py --root "../market_ticks/exchange=MEXC/stream=book_ticker" --pair SOLUSDT --start 2026-06-14 --output dist
```

Установка строит Next.js; отдельно build.py строит автономную разметку. Проверь /api/v1/health, doctor.py и обе вкладки. На Windows npm запускай какnpm.cmd. Не меняй глобальнуюполитикуPowerShell ради npm.

## Что уже сделано и чего пока нет

Разметка показывает потенциальные входы задним числом. Торговая модель должна выбирать вход по прошлому. Это разные проверки. Основныефайлы: lab_api.py, learn_jobs.py, learn_labels.py, learn_volume.py, harness_timed.py, build.py, engine.js и web/src.

ВходLONG — доступныйask после задержки 300ms, выходbid после задержки; комиссии за каждое исполнение и ухудшение цены учитываются по конфигурации. Текущие тарифы не считать доказанными навсегда: описанный 0.05% — параметр стартового сценария. Источники/ограничения вMEXC_FEES.md. SHORT в обучаемом дашборде отключён до фьючерсных котировок/расходов; наши MEXC-пятьпар здесь спотовые и сами по себе это ограничение не снимают.

Полный генетический поиск группV12 в этот сайт ещё не встроен. V12/Finam — отдельный исследовательский модуль вv12_source. Не утверждай, что имеющийсяdashboard уже умеет всё изV12.

Тесты из dashboard_source:

```powershell
python -X utf8 -m unittest test_learning test_timed
node test_engine.js
```

При изменении фронтенда пересобери web, проверь генерациюAPI-типов, откройбраузер ипройдиобе вкладки, один прогон, прогресс, остановку, рейтинг, входы/выходы, подсказки ификсацию. Перед изменением расчёта прочитайharness_timed.py и правила; все выводы о прибыли требуютчестного исполнения ирасходов.

Если в твоей среде нет доступа к загрузкам/установке/браузеру, скажи конкретно что недоступно. Не выдавай чтение инструкции за выполненный запуск. Если интернетPython закрыт, попроси владельца приложить скачанный ZIP — публичная ссылка не гарантирует сетевой доступ внутри любой ИИ-песочницы.
