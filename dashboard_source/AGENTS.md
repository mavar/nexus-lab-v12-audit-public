# Локальная лаборатория SOLUSDT

Начни с [project-passport/PROJECT.md](project-passport/PROJECT.md). Установка и восстановление — [TEST_LAB_SETUP.md](TEST_LAB_SETUP.md), поведение — [DASHBOARD_GUIDE.md](DASHBOARD_GUIDE.md).

- Сохраняй рабочие исходники и данные владельца. Исторические файлы, модели, секреты, зависимости и готовые сборки исключены из Git.
- Общайся кратко по-русски. Подписи и подсказки интерфейса должны быть понятны владельцу.
- Реальных сделок, переводов и подключения торговых ключей эта задача не разрешает.
- Исполнение хранится в harness_timed.py, правила — lab_rules.json. Изменения формул, комиссий, задержки и разделения по времени требуют подходящей проверки.
- Типы API генерируются из FastAPI. Стек Next.js + TypeScript + Tailwind + Recharts и loopback FastAPI сохраняется.
- После задачи выполни тесты Python, test_engine.js и сборку при изменении фронтенда. Проверь пользовательский сценарий и обнови паспорт.
- Работай в существующем чате. Не создавай новые видимые чаты без прямого запроса владельца.
