# Nexus MEXC — локальная лаборатория SOLUSDT

Основной запуск — **двойной клик по `START_LAB.bat`**, страница `http://127.0.0.1:8767/`.

На новом компьютере нужны Python 3.12, Node.js 24 LTS и Git. Первичная установка — `SETUP_LAB.bat`. Для проверки на искусственных данных — `SETUP_LAB.bat -Demo`. Затем `START_LAB.bat`. Подробности — [установка и восстановление](TEST_LAB_SETUP.md), [устройство и использование](DASHBOARD_GUIDE.md), [промпт для следующего ИИ](HANDOFF_PROMPT.md). Паспорт — [project-passport/PROJECT.md](project-passport/PROJECT.md).

Репозиторий закрытый. Скачать его может авторизованный владелец или среда с предоставленным доступом. Исходники, правила и генератор демонстрационных данных находятся здесь. Исторические котировки и сделки хранятся отдельно и подключаются через `local-config.json` или переменные окружения.

Два раздела интерфейса — просмотр разметки и тестирование алгоритмов. В обучении доступны дерево, логистическая модель и Байес, одиночный запуск, полный перебор выбранных значений, прогресс, остановка, рейтинг, графики и счётчики исходов. Для спотового обучения включён лонг. Шорт ожидает данные фьючерса и его расходы. Подробнее о точных правилах расчёта — [руководство](DASHBOARD_GUIDE.md).

Ниже описан отдельный автономный просмотр разметки.

## Автономный недельный просмотр

Локальная страница для сравнения разметки лонгов и условных шортов под разными ограничениями. Она не подключается к бирже. В репозитории только код; входные котировки и собранные страницы с ними хранятся отдельно. Часовой пояс интерфейса — UTC.

Для реальных исторических прогонов трёх правил используйте новый локальный экран через `START_LAB.bat` — см. [инструкцию запуска](TEST_LAB_SETUP.md). Прежняя статическая разметка сохраняется. Разделение на настройку и будущую проверку описано в [плане лаборатории](LAB_PLAN.md).

Нужны Python 3.12, зависимости из `requirements.txt` и современный Chrome/Edge с поддержкой `DecompressionStream`. Node.js нужен только для проверки расчёта. В папке клона:

```powershell
python -m pip install -r requirements.txt
node test_engine.js
python build.py --demo --output demo
```

Откройте `demo/OPEN_REVIEW.bat`; это синтетические котировки — около часа на каждый день. Для рабочей недельной страницы нужен локальный поток `book_ticker` с семью файлами Parquet и полями `recv_ts_ms`, `best_bid`, `best_ask`, `bid_qty`, `ask_qty`. Пример:

```powershell
python build.py --root 'G:\mexc_base\exchange=MEXC\stream=book_ticker' --pair SOLUSDT --start 2026-06-14 --output dist
```

На вашей машине путь к хранилищу может отличаться. Скрипт читает исходники без изменений и сохраняет даты, разрывы и хэши в отдельный манифест. Время получения котировки задаёт порядок; одинаковые времена сворачиваются по последней строке. Проверка сборки останавливается при недопустимых ценах или объёмах. `OPEN_REVIEW.bat` запускает страницу в браузере по умолчанию. Интернет и сервер не нужны.

1. Выберите направление и час, день, свой отрезок или неделю. Пределы оптимизации можно оставить пустыми. Нажмите выделенную кнопку; ход поиска показан над результатом, поиск можно остановить. Весь недельный перебор заметно дольше одного часа.
2. Рейтинг содержит каждую тройку срока, допустимого движения и цели из проверенной сетки. Фильтры «от/до» включают границы; сортировка по умолчанию по чистому итогу из условных 100 USDT. Строка возвращает исходный период, направление и точные параметры. Под итогом показана разбивка по дням для применённой строки. Поля с пределами поиска отдельно от фактически применённых настроек.
3. Покупка по ask, продажа по bid; для условного шорта наоборот. По обеим операциям 0,05% комиссии и 300 мс задержки. Лонг: `(выход × (1−f))/(вход × (1+f))−1`. Шорт: `(вход × (1−f)−выход × (1+f))/(вход × (1+f))`, условное полное обеспечение в USDT, без финансирования, заимствования и залоговых ликвидаций. Это не заявка, которую можно исполнить на споте. Падение для лонга считается от bid при входе, рост против шорта — от ask при входе. Выход после нарушения границы не допускается. Скачок данных более 2 секунд не соединяется; без покрытия окна метка не засчитывается.
4. Перебор выбирает лучший допустимый выход на каждую секунду и затем лучшую цепочку из этих меток, без перекрытий (одна позиция на оба направления). Это максимум среди размеченных выходов на сетке, а не максимум среди всех возможных выходов. В конце выбранного отрезка и в полночь новые позиции не переходят границу. Недельный остаток умножается на дневные коэффициенты по одним параметрам. Все успешные входы задним числом могут существенно перекрываться; количество сделок в цепочке меньше. Результат не измеряет доходность торговой стратегии.
