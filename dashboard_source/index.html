Как будем сравнивать

  1. Подготовим данные на июньской неделе, проверим отсутствие заглядывания вперёд. Настраивать будем только на ней.
  2. Запишем список вариантов, правила выхода и расходы до 23 ноября. В реальном времени выходить можно по цели, стопу или времени; лучший будущий выход годится только для разметки.
  3. После 29 ноября проверим запись и прогоним те же варианты без изменений. В отчёте будут чистый итог, просадка, число сделок и доля плюсовых отдельно по каждой неделе.

Если по ноябрьской неделе снова подбирать настройки, она перестанет быть независимой. Новую версию тогда проверим на следующей ещё не использованной неделе.
