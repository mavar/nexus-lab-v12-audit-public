# Как устроен дашборд

## Назначение

Локальная лаборатория помогает посмотреть разметку цен SOLUSDT, обучить простые модели на старых примерах и сравнить их работу на следующих днях. Отдельный просмотр показывает возможные удачные входы задним числом. Цена такого просмотра — ориентир для подготовки учебных меток.

Точка входа для владельца — `START_LAB.bat`, адрес `http://127.0.0.1:8767/`. Сайт работает, пока запущен локальный Python-сервис. После перезапуска компьютера его запускают снова. Для постоянной автоматической работы отдельная служба пока не настроена.

## Разметка

Кнопка «Разметка» открывает локальный `review.html` внутри страницы. В нём есть графики, цель после расходов, срок выхода, допустимое движение против позиции, направление и выбранный период. В автономной разметке могут рассматриваться условные шорты. Для одного момента может быть несколько удачных альтернатив. Количество удачных отметок и число реально последовательных сделок могут различаться.

Рейтинг разметки перебирает свою сетку срока, падения и цели. Сумма считается по цепочке совместимых сделок на одном балансе, с учётом расходов. Это расчёт по уже известным движениям цены. Для торговли входы должна выдавать модель по доступной в тот момент информации.

Сборка просмотра — `build.py`. Общий расчёт — `engine.js`, интерфейс — `app.js`, графики — `charts.js`, вкладка планирования — `lab.js`. Входные шаблоны входят в репозиторий, готовая страница с котировками создаётся отдельно.

## Обучение на разметке

Откройте «Тесты алгоритмов → Обучение на разметке».

1. Выберите дерево, логистическую модель или Байес. В текущем спотовом режиме используйте лонг.
2. Выберите «Один прогон» или «Автоподбор». Один прогон берёт введённые числа. Автоподбор использует каждое сочетание показанных значений.
3. Введите баланс и расходы. Стартовый баланс по умолчанию 100 USDT, комиссия 0,05% на каждое исполнение. Дополнительное ухудшение цены задаётся отдельно.
4. Для поиска задайте «От», «До» и «Точек». При «От 30, До 120, Точек 3» получатся 30, 75 и 120. При одинаковых границах укажите 1 точку.
5. Нажмите «Подобрать и проверить». Смотрите прогресс и число сравнённых настроек. Остановка завершит расчёт после текущего этапа.
6. Смотрите точные настройки выбранного результата, рейтинг, итоговый баланс, чистую прибыль или убыток, число прибыльных, убыточных и нулевых сделок.
7. На графике синий треугольник отмечает вход, зелёный ромб — прибыльный выход, красный крест — убыточный. Нажмите время сделки в таблице, чтобы рассмотреть её крупнее.

В начальной сетке 288 сочетаний. Параметры — чистая цель, предел движения против сделки, срок выхода, настройка модели, порог оценки входа, стоп по чистому убытку и окно объёма. Окно 0 отключает объём для сравнения, окна 60 и 120 секунд добавляют признаки сделок. Число сочетаний меняется вместе с числом разных точек. Невозможные варианты с недостатком учебных примеров учитываются как пропуски.

Обучение идёт на 14–17 июня 2026 UTC, сравнение настроек на 18–20 июня. Внутри учебной части используются признаки через каждые три секунды; на следующем отрезке решения возможны по секундной сетке. Шкала признаков обучается внутри каждой модели по учебным данным. Сравнение на использованном июне не заменяет проверку на свежей неделе.

Правило выбора в текущей программе даёт приоритет полному результату с минимум 20 закрытыми сделками. Затем сравнивает баланс, меньшую просадку и число сделок. Если никто не прошёл этот отбор, интерфейс подписывает пробный итог. Порог 20 относится к текущей функции выбора в интерфейсе. Общие строгие проверки исследовательской лаборатории описаны отдельно в `lab_rules.json`.

## Как считаются метки, признаки и деньги

В `learn_labels.py` признаки используют известные цены за 5, 15 и 60 секунд, колебания и разницу цены покупки и продажи. Учебная метка отвечает, можно ли было закрыть вход с заданной чистой целью в пределах времени и разрешённого движения против позиции. Будущие цены используются только при вычислении учебного ответа.

`learn_volume.py` читает реальные сделки. Считает число и объём за окно, ускорение, уровень с максимальным объёмом, расстояние до него и движение к нему, сильные уровни выше и ниже цены. Шаг уровня — 0,05 USDT. Время доступности сделки определяется получением данных. После паузы потока свыше двух минут окно заполняется заново.

`harness_timed.py` — сохранённый миллисекундный режим исполнения. Решение исполняется по первой реальной котировке через 300 мс или позже. Лонг покупается по ask, продаётся по bid. При расходе `f=feePct/100` чистый коэффициент сделки равен `exit/entry * (1-f)/(1+f)-1`. Дополнительное ухудшение цены повышает цену покупки и снижает цену продажи.

Цель, стоп, допустимое движение, время и конец дневной сессии могут дать команду на закрытие. Разрыв больше двух секунд не соединяется воображаемыми ценами. Если цены исполнения закрытия нет, позиция остаётся открытой, а показанный баланс относится к уже закрытым сделкам. Просадка в карточке считается по закрытым сделкам от предыдущего максимума, включая старт. На сделку используется весь свободный условный баланс. Минимум спотовой покупки — 1 USDT плюс комиссия.

Уровень цены и объём считаются по доступным данным. Модель видит признаки и выдаёт оценку входа. Порог оценки определяет, покупать ли. Более высокий порог обычно уменьшает число входов.

Дерево использует глубину и минимум 60 строк в ветке. Логистическая модель — нормализацию и коэффициент C. Байес — нормализацию и `var_smoothing=0.001*complexity`. В `learn_jobs.py` обучение, прогнозы и часть подготовки повторно используются для разных стопов и порогов.

## Простые правила

Отдельная кнопка «Простые правила» запускает три обычных входа — рост за несколько секунд, пересечение средних и пробой недавнего максимума. Их можно использовать для сравнения с обучением. Исполнение и расходы считаются тем же миллисекундным модулем.

## API и хранение

| Адрес | Назначение |
| --- | --- |
| `GET /api/v1/health` | Готовность, путь экземпляра, режим данных и наличие страницы разметки |
| `GET /docs`, `GET /openapi.json` | Документация FastAPI и схема |
| `POST /api/v1/learning` | Запуск обучения и поиска |
| `GET /api/v1/learning/{id}` | Прогресс и результат |
| `POST /api/v1/learning/{id}/cancel` | Остановка |
| `POST /api/v1/learning/{id}/freeze` | Сохранение модели для будущей недели |
| `POST /api/v1/runs` | Запуск простого правила |
| `GET /api/v1/quotes` | Котировки для подробного графика |
| `GET /label-review` | Автономный график разметки |

Сервис слушает только 127.0.0.1:8767. Одновременно выполняется один прогон. До четырёх последних заданий хранятся в памяти процесса и исчезают при его перезапуске. Зафиксированные модели хранятся в локальном профиле `NexusLabelLab/frozen-models`. Файлы моделей нельзя принимать из недоверенных источников.

## Будущая проверка и текущие границы

`check_frozen_week.py` рассчитан на отдельно подтверждённую неделю 23–29 ноября 2026 UTC. До её окончания программа проверку не запускает. Нужны фиксация до начала недели, паспорт качества записи, контрольные суммы источников, прежняя версия кода и модели. Смена кода после фиксации выявляется проверкой хэшей. Демонстрационные данные фиксировать запрещено программой.

Шорт в обучении пока ждёт подробные данные фьючерса SOL_USDT и его расходы. Полный поиск кластеров из 10 групп пока находится на стадии отдельной постановки задачи. `search_signals.py` — прежний ограниченный исследовательский прототип фильтров, запуск которого не встроен в интерфейс. Измеренный отдельно GPU-поиск соседей также ещё не встроен в дашборд.

## Стек и папки

Фронтенд — Next.js со статическим экспортом, TypeScript, Tailwind, простые компоненты в `web/src/components/ui` и Recharts. После сборки Node.js для обслуживания страницы не нужен. FastAPI одновременно отдаёт файлы `web/out` и API. `web/src/app/page.tsx` — основная страница. `web/src/lib/learning-controls.ts` — подписи, подсказки и сетка. Типы `web/src/lib/api.d.ts` генерируются из FastAPI, вручную их не меняют.

Для установки и поиска неисправностей используйте [TEST_LAB_SETUP.md](TEST_LAB_SETUP.md). Для передачи разработки — [HANDOFF_PROMPT.md](HANDOFF_PROMPT.md).
