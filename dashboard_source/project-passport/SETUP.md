# Установка

Единственная подробная инструкция — [TEST_LAB_SETUP.md](../TEST_LAB_SETUP.md). Python 3.12, Node.js 24 LTS. Программа установки использует .venv и npm ci, запуск выбирает .venv или прежние локальные библиотеки владельца.

local-config.json хранит только пути. Переменные окружения имеют приоритет. После смены путей перезапустите Python-сервис. На порту 8767 должен работать один выбранный экземпляр.
